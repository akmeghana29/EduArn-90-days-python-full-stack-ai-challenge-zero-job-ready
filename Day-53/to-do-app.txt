1. Project Overview

A Task Manager (or To-Do App) is a web application that
allows users to manage their daily tasks.

The application follows CRUD (Create, Read, Update, Delete)
operations and stores task information in a database.

It integrates:

• Frontend (HTML, CSS, JavaScript)
• Backend (Flask)
• Database (MySQL using SQLAlchemy ORM)

6. Feature 1 - Add Task

Purpose:

Allows users to create a new task.

Steps:

1. User enters task details.
2. Frontend sends a POST request.
3. Flask receives the request.
4. SQLAlchemy creates a new Task object.
5. Object is stored in MySQL.
6. Updated task list is displayed.

Flow:

User
↓

Enter Task

↓

POST Request

↓

Flask Route

↓

Database

↓

Task Saved

----------------------------------------------------------
7. Feature 2 - View Tasks

Purpose:

Displays all tasks stored in the database.

Steps:

1. Flask retrieves all task records.
2. SQLAlchemy converts database rows into Python objects.
3. Data is sent to a Jinja2 template.
4. HTML page displays all tasks.

Common ORM Method:

query.all()

----------------------------------------------------------
8. Feature 3 - Update Task

Purpose:

Allows users to modify an existing task.

Examples:

• Change title
• Change description
• Mark as completed

Steps:

1. User selects Edit.
2. Existing task is loaded.
3. User updates information.
4. Flask receives updated data.
5. Database record is modified.
6. Changes are committed.

Common ORM Method:

db.session.commit()

----------------------------------------------------------
9. Feature 4 - Delete Task

Purpose:

Removes a task permanently.

Steps:

1. User clicks Delete.
2. Flask identifies the task by ID.
3. SQLAlchemy removes the object.
4. Changes are committed.
5. Updated task list is displayed.

Common ORM Method:

db.session.delete()

16. Benefits of SQLAlchemy

• No need to write raw SQL for most operations.
• Easier CRUD implementation.
• Database-independent code.
• Better readability.
• More secure against SQL Injection.
