1. What is Database Design?

Database Design is the process of planning how data will be
stored, organized, and related inside a database.

A good database design helps in:

• Reducing data duplication
• Improving performance
• Maintaining data integrity
• Making data easier to retrieve
• Scaling applications efficiently

6. Primary Key

A Primary Key uniquely identifies each record.

Properties:

• Unique
• Cannot be NULL
• One primary key per table

Example:

Student_ID

----------------------------------------------------------
7. Foreign Key

A Foreign Key creates a relationship between tables.

Example:

Students Table

Student_ID (PK)

Marks Table

Student_ID (FK)

13. Normalization

Normalization is the process of organizing data
to reduce redundancy and improve consistency.

Goals:

• Remove duplicate data
• Improve data integrity
• Reduce storage
• Simplify updates

----------------------------------------------------------
14. First Normal Form (1NF)

Rules:

• Each column contains a single value.
• No repeating groups.
• Each row is unique.

Incorrect:

Student

Kirti

Subjects

Math, Science

Correct:

Student

Subject

Kirti

Math

Kirti

Science

----------------------------------------------------------
15. Second Normal Form (2NF)

Rules:

• Must satisfy 1NF.
• Remove partial dependency.
• Every non-key attribute should depend on
the entire primary key.

----------------------------------------------------------
16. Third Normal Form (3NF)

Rules:

• Must satisfy 2NF.
• Remove transitive dependency.
• Non-key attributes should depend only
on the primary key.

----------------------------------------------------------
17. Denormalization

Denormalization intentionally adds redundant data
to improve query performance.

Advantages:

• Faster reads
• Fewer joins

Disadvantages:

• More storage
• Possible data inconsistency

20. Indexing

An Index speeds up data retrieval.

Advantages:

• Faster SELECT queries
• Faster searching

Disadvantages:

• Uses extra storage
• Slightly slower INSERT, UPDATE, DELETE

23. Best Practices

• Use meaningful table names.
• Use meaningful column names.
• Choose appropriate data types.
• Avoid duplicate data.
• Use Primary Keys.
• Use Foreign Keys.
• Normalize when appropriate.
• Create indexes for frequently searched columns.
• Keep relationships simple.

24. Common Interview Questions

Q1. What is Database Design?

It is the process of organizing data into tables,
relationships, and constraints for efficient storage
and retrieval.

--------------------------------

Q2. What is Normalization?

The process of reducing redundancy and improving
data consistency.

--------------------------------

Q3. What is Denormalization?

Adding controlled redundancy to improve performance.

--------------------------------

Q4. Difference between Primary Key and Foreign Key?

Primary Key

Uniquely identifies each row.

Foreign Key

References the Primary Key of another table.

--------------------------------

Q5. What is a Junction Table?

A table used to implement a Many-to-Many relationship.

--------------------------------

Q6. What is an ER Diagram?

A diagram that represents entities, attributes,
and relationships.

--------------------------------

Q7. Why are indexes used?

To improve query performance.

--------------------------------

Q8. What are the three most common relationships?

• One-to-One
• One-to-Many
• Many-to-Many

Summary

Database Design is the foundation of every database-driven
application. It involves identifying entities, attributes,
relationships, keys, and constraints while applying
normalization principles to minimize redundancy and improve
data integrity. A well-designed database is easier to
maintain, faster to query, and scalable for future growth.
