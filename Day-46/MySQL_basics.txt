----------------------------------------------------------
1. What is MySQL?

MySQL is an open-source Relational Database Management
System (RDBMS) used to store, organize, and manage data.

It stores data in the form of tables consisting of rows
and columns.

MySQL uses SQL (Structured Query Language) to interact
with databases.

----------------------------------------------------------
2. Why Use MySQL?

Advantages:

• Open Source
• Fast
• Secure
• Reliable
• Supports Large Databases
• Easy to Learn
• Widely Used in Web Applications

4. Database

A Database is an organized collection of related data.

Example:

College Database

├── Students Table
├── Teachers Table
├── Courses Table
└── Marks Table

----------------------------------------------------------
5. Table

A Table stores data in rows and columns.

Example:

Students

+----+--------+-----+
| ID | Name   | Age |
+----+--------+-----+
| 1  | Kirti  | 21  |
| 2  | Rahul  | 22  |
+----+--------+-----+

----------------------------------------------------------
6. Row (Record)

A Row represents one complete record.

Example:

1 | Kirti | 21

----------------------------------------------------------
7. Column (Field)

A Column represents one attribute.

Example:

ID
Name
Age

----------------------------------------------------------
8. Primary Key

A Primary Key uniquely identifies every record.

Properties:

• Unique
• Cannot be NULL
• One Primary Key per table

Example:

Student_ID

----------------------------------------------------------
9. Foreign Key

A Foreign Key creates a relationship between two tables.

Example:

Students
---------
Student_ID (PK)

Marks
------
Student_ID (FK)

----------------------------------------------------------
26. Difference Between DELETE, TRUNCATE and DROP

DELETE

• Removes selected rows.
• Table remains.
• Can use WHERE clause.

TRUNCATE

• Removes all rows.
• Table remains.
• Cannot use WHERE clause.
• Faster than DELETE.

DROP

• Deletes the entire table.
• Both data and structure are removed.

27. Constraints

PRIMARY KEY
Uniquely identifies each record.

FOREIGN KEY
Creates relationships between tables.

UNIQUE
Ensures all values are unique.

NOT NULL
Does not allow NULL values.

DEFAULT
Assigns a default value.

CHECK
Restricts values based on a condition.

Summary

MySQL is a Relational Database Management System (RDBMS)
that stores data in tables. SQL is used to create databases,
define tables, insert, retrieve, update, and delete data.
Core concepts include primary keys, foreign keys,
constraints, data types, and SQL commands such as CREATE,
INSERT, SELECT, UPDATE, DELETE, TRUNCATE, and DROP.
